> **NOTE:**  Selv is in beta and can have bugs.  


Selv is a free and open-source desktop application that makes creating and managing Minecraft servers simple and accessible. It allows you to host servers directly on your own computer, giving you control over your game worlds without relying on a traditional server hosting provider.

Whether you want to play with a few friends or share your server with a larger community, Selv aims to make server management accessible to everyone.

Consult the full documentations on https://docs.selvmc.com

## Key features
### Simple of use
Selv aims to make Minecraft servers management and creation easy and accessible. Therefor, the software provides a simple interface where your server settings can be changed in a click and all the server-creation process is automatic.

### Customized connection address
For each of your servers, you can claim a free customized IP connection address. The server's traffic will, when this option is enabled, be tunneled through our servers to and from your players. They can use the address it to connect to your server easily. The IP address will follow the format: [custom-ip].selvmc.com.  

### Security
Regular server hosting on your own machine can be quite a security hasard: It usually requires you to share the public IP address of your PC and to open ports on your internet router. This open door on your network can have undesirable consequences.  
Selv's tunneling adds a layer of security and privacy by hiding your real IP address (untracable, only our server's address can be seen) and not having you open any port on your router.

### Compatibility
Selv's allow you to create servers in all Minecraft versions\* and using 4 different engines : 

| **Engine** | **Description** |
| --- | --- |
| Vanilla | **Default** Minecraft |
| Forge | You can add **mods**, a type of extensions that can add new blocks and mechanics |
| Spigot | You can add **plugins**, a type of extensions that can add new commands and server functionalities |
| Paper | A lightweight equivalent of Spigot, with equal **plugins** compatiblity |

Selv also solves Java versions compatibility problems between Minecraft versions by download separate Java versions and choosing the right one for each individual server

 _\*: versions often starting at 1.8, not all are available depending on the sources we download them from._
